# Customer portal links

Filament classes:

- `App\Filament\App\Pages\CustomerPortalLinks`

## When to use

Copy or manage links for customer-facing portal access (invites, deep links, partner self-service URLs).

## Prerequisites

- Customer portal features enabled for the tenant profile.
- Permission to view or regenerate portal links.

## Steps

1. Open **Customer portal links**. Open the page and use Help for live UI.
2. Select the customer / partner context if prompted.
3. Copy the appropriate link; share via approved secure channel.
4. Rotate or revoke links when access should end.
