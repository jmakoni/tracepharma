# Settings hub

Filament classes:

- `App\Filament\App\Pages\SettingsHub`
- `App\Filament\App\Pages\OrganizationSettings`
- `App\Filament\App\Pages\DashboardPreferences`

## When to use

Navigate tenant settings, edit organization profile, and personalize your dashboard preferences.

## Prerequisites

- Organization settings typically require tenant admin.
- Dashboard preferences are per-user.

## Steps

1. Open **Settings** hub for the index of setting areas. Open the page and use Help for live UI.
2. Open **Organization** to edit company profile, defaults, and policy toggles.
3. Open **My dashboard** to choose widgets and layout preferences.
4. Save and verify the home dashboard reflects changes.

- Dashboard preferences never change shared compliance configuration.
