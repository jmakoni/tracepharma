# Pms And Wholesaler Packs

Filament classes:

- `App\Filament\App\Pages\PmsIntegrationChecklistPage`
- `App\Filament\App\Pages\WholesalerIntegrationPackPage`

## When to use

Follow pharmacy PMS or wholesaler/WMS integration checklists covering connectivity, mapping, and go-live gates.

## Prerequisites

- PMS or WMS vendor contact and technical owner on your side.
- API tokens / connections available as the checklist requires.

## Steps

1. Open **PMS integration** or **Wholesaler / WMS pack**. Open the page and use Help for live UI.
2. Work checklist items in order; mark complete as each gate passes.
3. Attach or link evidence (sample files, successful jobs) per item.
4. Exit when all critical gates are green; park nice-to-haves as follow-ups.
