# Leadership Dscsa Pack

Filament classes:

- `App\Filament\App\Pages\LeadershipDscsaPack`

## When to use

Give executives a concise DSCSA readiness snapshot: exceptions aging, ATP gaps, ingest health, recall/inspection status, and key KPIs.

## Prerequisites

- Leadership or compliance role with access to the pack page.
- Underlying metrics jobs have run for the selected period.

## Steps

1. Open **Leadership DSCSA pack**. Open the page and use Help for live UI.
2. Select period / site scope if offered.
3. Review KPI cards and drill-through links into operational pages.
4. Export or screenshot only if your leadership process requires offline sharing (prefer live links).
