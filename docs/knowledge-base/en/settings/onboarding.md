# Onboarding

Filament classes:

- `App\Filament\App\Pages\OnboardingWizard`

## When to use

Walk a new tenant through first-time setup: organization, sites, users, partners, and initial integrations.

## Prerequisites

- New or partially configured tenant.
- Admin user who can complete all wizard steps.

## Steps

1. Open **Getting started**. Open the page and use Help for live UI.
2. Complete each step in order; skip only when intentionally deferred.
3. Finish with a smoke receive/ship or ingest check if offered.
4. Return later to close any skipped optional steps.

- Wizard progress is advisory once you leave early — unfinished steps still block some workflows.
- Demo tenants may pre-seed data; do not assume blank master data.
