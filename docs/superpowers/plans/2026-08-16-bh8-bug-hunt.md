# BH8 Bug Hunt Implementation Plan

> Spec: `docs/superpowers/specs/2026-08-16-bh8-bug-hunt-design.md`

**Goal:** Floor ship/transfer scan parity + outbound-kill truthful ship UX + MDN/VRS SiteAccess edges; then SFTP legacy cleanup + aggregation FK doctor ops.

**Architecture:** Mirror BH7-7 receive scan pattern on ship/transfer; fail-closed ship complete/UX when transmit killed/failed; MDN uses `OUTBOUND_EPCIS`; reuse `SiteAccess::constrainVerifications`.

**Tech Stack:** Laravel 13, Filament 5, Stancl, Pest. Prefer `DatabaseTransactions` for Admin; no central `RefreshDatabase`.

## Global Constraints

- No branding/Stripe/full AS2 inbound product unless stretch BH8-8.
- Minimal diffs; TDD; Support least-privilege unchanged.
