# Demo Requests

Filament classes:

- `App\Filament\Admin\Resources\DemoRequests\DemoRequestResource`

## When to use

Triage inbound demo / trial requests from the marketing site or sales forms.

## Prerequisites

- Admin access to demo requests.
- Process for converting demos to customer onboarding.

## Steps

1. Open **Demo requests**. Open the page and use Help for live UI.
2. Qualify the request; assign owner and status.
3. Schedule / deliver the demo; record outcome notes.
4. Promote successful demos into [customer-onboarding.md](../tenants/customer-onboarding).

## Notes

- Spam and duplicate requests are common — dedupe by email/company before provisioning.
- Do not put secrets in demo request notes.
