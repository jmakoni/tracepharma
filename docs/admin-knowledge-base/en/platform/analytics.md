# Analytics

Filament classes:

- `App\Filament\Admin\Pages\PlatformAnalytics`

## When to use

View platform-wide analytics: tenant growth, onboarding funnel, demo volume, import trends, match aging, hub coverage, and activity volume.

## Prerequisites

- Admin access to platform analytics.
- Widgets enabled in dashboard preferences / platform dashboard settings as applicable.

## Steps

1. Open **Platform analytics**. Open the page and use Help for live UI.
2. Select period if offered; scan for aging queues and import health.
3. Drill into operational resources (imports, match review, onboardings) for remediation.
4. Share summaries with leadership without exporting raw PII.
